No API request, account action, API Use Form submission, or external contact
occurred. It does not determine the applicable Gemini entity, User Agreement,
jurisdiction, commercial status, or legal permission for MIDAS.

Gemini's [Market Data Agreement](https://www.gemini.com/legal/market-data-agreement)
is dated 12 October 2025. It grants a non-exclusive, non-transferable,
revocable license for stated personal/internal, informational, and price/market
analysis uses subject to prohibited-use restrictions. It prohibits
redistribution, specified financial-product activity, and creating or using a
financial benchmark, reference rate, or index. It directs commercial-purpose
requests to Gemini. The [API Agreement](https://www.gemini.com/legal/api-agreement)
says public market-data API requests do not require an API key, sets a public
request limit of up to 120 per minute, and asks API users to complete an API
Use Form. The applicable residency-specific User Agreement and MIDAS
organization, retention, internal display, and research scope remain
unreviewed; the form has not been submitted.

The API documentation establishes technical availability, not intended-use
authorization, jurisdictional access, current book quality, or usable trading
economics. The adapter therefore remains behind an unconditional source-use
hold. It uses no credentials or trading endpoints; its documentation-shaped
fixtures establish parser behavior only. Do not collect Gemini data or use
retained Gemini observations in research until the applicable agreements and
intended scope have been reviewed through an authorized process.
